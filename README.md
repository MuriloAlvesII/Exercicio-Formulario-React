# Objetivo

Criar uma aplicação web utilizando React, com o objetivo de implementar formulários por meio de componentes reutilizáveis, utilizando inputs para receber os dados inseridos pelo usuário e exibindo essas informações em Cards. Dessa forma, podemos entender essa estrutura como um cadastro de livros em um sistema de biblioteca, no qual os livros são separados pelo ano de publicação e são apresentadas informações básicas sobre eles, como título, autor e gênero.
